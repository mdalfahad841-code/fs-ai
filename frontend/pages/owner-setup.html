FS AI — Owner Login Setup

Use this page if you forgot the Command Center password: make a new hash below, then replace the OWNER_PASSWORD_HASH variable in the Cloudflare Worker settings (Settings → Runtime variables and secrets) and save. Your old password stops working as soon as the Worker redeploys.

← Back to Command Center

Everything on this page runs in your phone's browser only. Your password is never sent anywhere — the hash is made on your device. Send only the hash (not the password) to Faru, or paste it straight into the Worker settings yourself.

1. SESSION_SECRET (random code)

Tap Generate, then copy the code. This goes into the Worker as a variable named SESSION_SECRET.

2. OWNER_PASSWORD_HASH (from your password)

Type the password you want for the Command Center login, then tap Generate hash. The output goes into the Worker as a variable named OWNER_PASSWORD_HASH.

Keep the password written down somewhere safe (your own notebook / password manager). If you lose it, login can be reset only by making a new hash and replacing the variable.
