The comment's premise — "the Worker's connection does not run `PRAGMA foreign_keys = ON`, so the cascade may NOT fire" — describes stock SQLite defaults, not D1's managed behaviour. **Direct live proof is NOT TESTED**: no article has ever been deleted on live D1 (see check 5), so no delete has ever exercised the cascade; proving it would require deleting a real article, which this read-only inspection does not do.
